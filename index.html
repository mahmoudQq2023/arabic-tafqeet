arabic-tafqeet

Spell numbers and amounts in Arabic words — تفقيط — the way cheques and invoices need them. One file, no dependencies, MIT.

Use it

import { tafqeet, tafqeetAmount } from './tafqeet.js';

tafqeet(1250750);       // مليون ومائتان وخمسون ألفاً وسبعمائة وخمسون
tafqeetAmount(1250.5);  // فقط ألف ومائتان وخمسون جنيهاً وخمسون قرشاً لا غير

Why each rule exists, and the bugs that found them: Spelling numbers in Arabic is harder than it looks.

Beyond this library

This code counts masculine nouns in two currencies. For riyal, dirham and dinar, and for turning Arabic words back into digits, use the free online converter تفقيط الأرقام — Arabic number to words for cheques and invoices, part of Confileo, where this code came from.
